# Hotel PMS Documentation

## Source of Truth

- `project-overview.md`: project scope and current domain boundaries.
- `features/`: business workflows and business rules.
- `api/api-guidelines.md`: common API implementation rules.
- `api/api-contracts.md`: endpoint-level API contracts.
- `api/authorization.md`: authentication, roles, and permission rules.

`hotel-pms-requirements.md` is a legacy document. It may contain requirements
that are no longer in scope, especially product, service, payment, and IoT
features. Do not use it as the primary source of truth.
